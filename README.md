<h1 align="center">TaskFlow</h1>

TaskFlow is a Next.js-based productivity task manager with full PWA (Progressive Web App) support, offline capability, and installability.

## Documentation

- [Development Guide](docs/DEVELOPMENT.md)
- [PWA & Installability](docs/PWA.md)
- [Deployment Guide](docs/DEPLOYMENT.md)

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Features
- Next.js 16, React 19, Tailwind CSS
- PWA installability (manifest, service worker, offline support)
- Custom install prompt button
- Deploy-ready for Vercel

## Project Structure
- `src/app/` — Main app code
- `public/` — Static assets (manifest, icons, service worker)
- `docs/` — Project documentation
